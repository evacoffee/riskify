risk management :)

allows users to enter stock ticker and date range, run a backtest, and view preformance metrics.

## features
- historical market data using Yahoo Finance
- moving-average trading strategy
- Backtesting engine
- total return calculation
- volatility calculation
- sharpe ratio calculation
- maximum drawdown calculation

## development
1.) clone this repo
```sh
git clone https://github.com/evacoffee/riskify.git
```
2.) enter the project folder
```sh
cd riskify
```
3.) install dependencies
```sh
pip install -r requirements.txt
```
4.) start riskify 
```sh
python app.py
```
